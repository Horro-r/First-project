# First-project
# Дисциплина: Введение в профессиональную деятельность
Данный проект направлен на: создание игры, которая является мои семестровым заданием; получение новых знаний; выработку эффективного плана для самоорганизации.

## О проекте
Создание пиксельной 2D-игры в жанре Horde Survival
Для начала разберемся, что такое Horde Survival. _Horde Survival (от англ. horde — «орда» и survival — «выживание»)_ — это поджанр экшен-игр, в котором основной задачей игрока является выживание как можно дольше на ограниченном пространстве против непрерывно нарастающих волн врагов.

Игровой процесс происходит на двухмерной (2D) арене с видом сверху. Камера неотступно следует за персонажем. В отличие от классических RPG, здесь нет сложных диалогов или платформинга. Вместо этого классические элементы прокачки (рост характеристик и выбор улучшений) тесно переплетены с динамичным экшеном: персонаж автоматически атакует ближайших противников, а игрок должен грамотно перемещаться по арене, уклоняться от орд врагов и собирать опыт для повышения уровня и получения новых способностей.

### Используемые инструменты:
Движок: Godot Engine (выбран из-за легковесности, открытого исходного кода и поддержки 2D-график).
Графика и анимация: Piskel (бесплатный онлайн-редактор, использовался для покадровой отрисовки пиксель-арт спрайтов).
