# Дисциплина: Введение в профессиональную деятельность
Данный проект направлен на: создание игры, которая является мои семестровым заданием; получение новых знаний; выработку эффективного плана для самоорганизации.

## О проекте
Создание ARG 
Для начала, что такое ARG?
_АРГ (или ARG — Alternate Reality Games)_— это интерактивная форма повествования, которая стирает грань между вымыслом и реальным миром.
* Принцип TINAG (This is not a game — «Это не игра»): События подаются так, будто всё происходит наяву
* Инструменты: Используются сайты, реальные телефонные номера, соцсети, видеоролики и даже физические геометки
* Роль игрока: Вы не управляете аватаром, а действуете от собственного лица, решая головоломки вместе с другими участниками
