Данный проект направлен на: создание игры, которая является мои семестровым заданием; получение новых знаний; выработку эффективного плана для самоорганизации.

## О проекте
Создание пиксельной сайд-скроллер RPG 
Для начала, что такое сайд-скроллер RPG?
_Сайд-скроллер RPG (от англ. side-scroller — «прокручивающийся сбоку»)_ — это ролевая игра, в которой игровой мир отображается сбоку, а камера двигается вслед за персонажем по горизонтали (влево/вправо и вверх/вниз). В такой игре классические элементы RPG (прокачка, характеристики, экипировка и сюжет) совмещены с механикой перемещения в двухмерной (2D) плоскости, где важную роль играют прыжки, платформы и преодоление препятствий.
